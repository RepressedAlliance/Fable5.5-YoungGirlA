# 制作手记：从一个代号到一个人

这篇整理自仓库内的方案、分镜、修改清单及现有代码。它说明为什么这样做，以及哪些问题推动了返工；不把早期计划写成已经实现的结果。完整修改历史见[文档索引](README.md)。

## 先给画面一个贯穿全片的问题

主题不是“让 AI 为歌曲配一些好看的画面”，而是：所有人都在谈论少女A，谁真正关心她？这个问题决定了视觉材料：报道、评论、手机、热搜、证件照、旧作业和姓名栏。每种材料都在做同一件事——替她定义身份。

遮眼黑条也因此不仅是装饰。前半段它替外界隐去她；后半段她自己也用这个代号看待自己；最后必须由她亲手擦掉。尾奏落到一张表格和一支笔，故事才从别人的说法回到她的选择。

早期方案只想让她写下第一笔就切黑，实际尾奏写出了“鏡音リン”。这类变化保留在原始记录里，阅读时要回到成片和当前代码核对。

## 色板和版面要服务叙事

基础色是青 `#03C3FB`、墨黑 `#0A0A0F`、纸白 `#F6F3EA`、金黄 `#FEE45F` 和有限的红。报道与信息流用密集文字、硬边块面和印刷语言；进入房间后，以低饱和的暗蓝压低世界。开眼以后恢复人物本色，变化就有了叙事意义。

日文文字不是最后贴上的字幕。标题、评论和纸带都是画面对象。`engine.Type`、`fit` 与 `typo.engine` 先测量字形，再安排字号和位置；竖排交给 HarfBuzz 的纵向排版，而不是把横排字逐个旋转。

## 人设图比越来越长的提示词更重要

一张[定稿人设](人设_定稿_c.png)固定脸型、比例、蝴蝶结、校服、围巾和线条。之后的角色生成都带这张图，用统一提示词约束画风，再用当前镜头说明动作。

最容易露馅的不是角色名字，而是放大后新增的东西：过密的发丝、写实手部、关节线、复杂衣褶、柔光、粉腮红或吉祥物比例。因此提示词里专门补了手部规则和大特写规则，并要求新图与片中已经成立的好图并排比较。

关键决定是：**人物主体用带参考的整张原画，代码处理动画与合成。** 早期结尾尝试用程序拼人物，被否定后转回整张生成，再对齐眼睑、嘴和风中头发。见[问题根因清单](问题根因清单.md)、[结尾重做](结尾重做.md)和[结尾处理脚本](../work/eye/key6/build_end.py)。

## 动作不是放大缩小一张图

奔跑、停步、跌倒、抬手和风中的头发需要清楚的关键姿态。素材文件的 `_a`、`_b`、`_c` 等变体提供换张基础，代码再控制相机、停留时间、落点和节拍。

结尾写字尤其如此：手不能沿一条线滑过去，而笔尖在另一处出墨。`s13b.py` 将持笔关键图、笔尖位置、落笔和抬笔、笔画路径共同约束。学这个做法时，先看接触点是否成立，再加速度和镜头。

## 三维先解决空间，再决定怎样画

校门、鞋柜、电车和教室需要可信的透视、尺度与遮挡，所以用 Blender 搭空间；但画面不追求默认的写实渲染。Cycles 提供数据通道，`src/npr/` 再决定块面、阴影和轮廓。

这也让几何错误和画风错误能分别处理：抽屉朝向错，要改场景；阴影或线条不对，可在保留通道上重上色。两者不能互相遮掩。

第五版反馈还指出三维空间“太空”。这不是添几个装饰物能解决的：主题是所有人都在谈论她，场景里却没人。于是校门补入记者和旁观者，鞋柜边补学生，电车补乘客，并让手机、广告和场景中的报道继续指向她。**空间里的人，也要在演同一个故事。**

## 音节是动作发生的时刻

重复词、快门、纸张撞击、榜单变化和眼睛亮起，都要有音乐上的落点。工程用统一歌曲时间，不让每段各自从零猜测节奏。

节拍检测只给出候选。逐字轴读取自备卡拉 OK 时间，再映射到日文字符，最后仍需要听校。开眼段的“光逐层出现”尤其不能只做成一个匀速变亮的遮罩；亮起、停顿、高光和视线要一起排演。

## 修一个问题，查一类问题

修改清单里反复出现的是接触、比例和因果：手为什么显老，人物为什么没有脚，纸为什么像印在桌上，校门与手机照片为什么切得断，前后镜头的动作为什么没接上。

[根因清单](问题根因清单.md)把具体反馈变成一类检查项。以手为例，只改某张图的颜色不够；要同时检查生成参考、比例约束、近景细节密度、袖口宽度，以及全片同类镜头。

审片也不能只和上一版比较：上一版更差，并不等于这一版已经好。用人设和已经成立的片中镜头作基准；保护被认可的段落，对修改范围保持清楚。第五版反馈中对后半段的肯定与保留要求，正是这种取舍的记录。

## 值得借鉴的不是某个模型名

这个项目留下的可参考部分是：一个明确主题，一套视觉规则，一张稳定人设，一份歌曲时钟，一组可定位的渲染段落，以及把审片反馈转为根因和代码修改的方法。

Claude Code 负责构想、分镜、代码与合成，Codex 按人设生成角色材料，作者持续决定方向并审片。仓库保留具体文件，是为了让这些选择有据可查，而不是把成片描述成一句提示词自然完成的结果。
