# 结尾重做（201.4–206，2026-11-06 用户看过后决定）

用户原话：图二（201.5 的亮色主视觉）“还是太丑了”，“图一到图二太生硬了”，“考虑这里重新做”。用户此前还说过：动态非常好，但平涂正脸“静态的看有点劣质”，嘴一直平着，可以笑一笑。这一刻是全片的点睛之笔。

## 诊断
- 丑：脸小，眼睛小，大部分面积是吹开的头发和纯色底，像通用的矢量吉祥物；全片最有力量的那双大眼睛不见了。
- 生硬：从暗部正脸大特写硬切到另一张图，角度、脸型、眼睛、景别、构图全变，观众感觉换了一个人，前面攒的张力被切断。

## 新方案：不切，光从眼睛溢出来
1. 201.4 之前的光逐层亮起不动，动画和那双眼睛（work/eye/v4_a1_1.png）照旧。擦黑条的手单独修。
2. 乐队回来的那一拍（201.4），**同一张脸、同一条线稿、同一个机位**：颜色从那双眼睛向外亮开，语言和虹膜相同，硬边分层、一档一档，不是柔光也不是叠化，按二拍走。全片暗部的蓝被她自己的颜色取代，先脸，再头发和蝴蝶结，最后背景。歌词纸条可以被这一下风带走。
3. 颜色到齐后，镜头才从大特写慢慢松开（可以带一点点旋转，让正脸不僵），露出蝴蝶结、被风吹动的头发、灰围巾，停在**她仍然占满画面、眼睛依然很大**的景别。眨眼，然后全片唯一一次小小的笑，一直留到 206。

## 原画要求
- 线稿、脸型、眼睛必须和暗部大特写（assets/gen/cut/p05_face_close.png）完全对齐：它就是同一张画。
- 静态要耐看：线条有粗细，头发至少三档硬边影，脸上有硬边的影（刘海投影、鼻下、下巴下到脖子），腮红不能是贴上去的粉椭圆。不许柔光渐变，不许头发碎成细丝，不许衣褶堆满，不许矢量吉祥物感。14 岁比例，蝴蝶结两瓣，灰围巾，眼睛碧青。
- 背景不要只是一片纯青：可以保留青色这个她的颜色，但要有印刷风格的硬边设计，让它值得看。

## 定稿方向（我的判断，03:05 全尺寸比较两版后改定）
用 c6.py 里工作流 finale-redo 这一版做底：背景是她的虹膜放大成的天空，接上“光从眼睛溢出来”；发色贴近人设，线条干净，笑得舒服。c6_end.py 的候选 c 版颜色硬、线粗脏，不用，只移植它的构思：黑条被撕碎吹走，碎片上有手写的“少／女A”，是真的在动的图层。

等工作流做完后还要改：
1. 光扩散的中途不能像眼罩或泳镜（两版都有，因为波前是从两只眼睛各自长出来的）。
2. 灰围巾要看得见地围在脖子上，现在几乎只剩一条尾巴。
3. 蝴蝶结不能顶到画框，瓣形要接近人设的尖两瓣，不要压得太扁。
4. 查视线：205.5 右眼虹膜略偏内，双眼要平行。
5. 头发的高光：人设上没有，要留就要干净，不能有锯齿。
