# 问题根因清单

用户 2026-11-06：“凡是我找出来的问题，都不能只修我指出来的地方，不能治标不治本，要根源性解决。”

用户指出的每个问题都是一类问题的样本。收到问题后按这个顺序处理：查出成因，写进这里，查全片同类的地方，改掉成因，再改同类。之后每轮审查和交付前都要逐项过这张表。做新素材时也按它检查。

**硬规则（用户 2026-11-06）：人物主体必须由 Codex 带人设图整张生成（src/tools/codex_gen.py）。代码只做动画、换张、合成和小修补，不能用来画她。对齐等技术需求不是例外。验收时和 assets/gen/cut/p01_bust_front.png 等片中好图并排看，不和上一版比。**

用户的总判断（2026-11-06）：用人设图 docs/人设_定稿_c.png 参考出来的图几乎没有 AI 感，大部分地方没问题。问题在于画风简单，有些做出来很丑（结尾主视觉、切入它的那一刀、擦黑条的手）。所以生图一律带人设图参考，并对照它判断；不要加人设里没有的东西（粉腮红、吉祥物比例、写实的手）；图放得很大时，靠线条、比例、形状设计和硬边阴影撑住；没问题的图不要重画。
