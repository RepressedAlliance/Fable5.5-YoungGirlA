# 镜音铃设定分层（角色生成与审查的依据）

用户要求（2026-11-03）：官方基础设定必须遵守；白色蝴蝶结这类只是锚点，可以修改；服装同理，可以调整。三层要仔细区分。

## 第一层：官方基础设定（必须遵守，不改）

| 项目 | 设定 | 依据 |
|---|---|---|
| 年龄 | 14 岁 | piapro 官方角色页「Age: 14」 |
| 身高 / 体重 | 152 cm / 43 kg：14 岁少女的身材比例，不画成成人或幼儿 | piapro 官方角色页 |
| 眼睛颜色 | **偏青的蓝绿色（碧色）**，不是深蓝或藏青。官方设定图实测：虹膜暗部约 #048396 → 中间 #218EA3 → 下半亮部 #5BB8CA → 高光 #B0E8EA | piapro 官方服装设定图 `official_cos_rin.jpg`（KEI）实测；独立来源 MyWaifuList 写作 blue-green，Project DIVA Wiki 写作 blue |
| 眼型 | 大而圆的眼睛 | 官方插画、设定图 |
| 发色 | 明亮的金黄色（设定图实测约 #FEE45F），不是棕金或白金 | 官方设定图实测 |
| 发型 | 齐下巴的短波波头，带刘海 | piapro「blonde bob」 |
| 肤色 | 白皙 | 官方设定图 |
| 代表色 | 橙色（官方文字）；官方插画里黄、橙作点缀 | piapro「Color: Orange」 |

## 第二层：辨识锚点（必须保留，具体设计可改）

| 锚点 | 必须保留什么 | 可以改什么 |
|---|---|---|
| 头顶大蝴蝶结 | 头顶有一个**大**蝴蝶结，剪影一眼可认 | 颜色、材质、形状、系法、是否有发箍 |
| 金色短发剪影 | 波波头轮廓 | 发束的具体设计 |
| 刘海上的发夹 | 建议保留（官方设定图：她右侧刘海上两枚平行白色发夹；多个独立来源都提到） | 颜色、形状、数量 |

## 第三层：可以自由设计

- 服装：官方的水手领、白色无袖上衣、黄色领巾、灰色短裤、袖套腿套、腰链、“02”肩部标记、耳机，全部可以按本片世界重新设计（可以借用其中一两个元素作呼应）。
- 耳机 / 头戴设备、鞋、配饰。
- 表情、动作、表演风格。

## 审查方法
- 每张生成的角色图对照本文件逐层检查：第一层任何一项不符就重画；第二层看剪影是否还能一眼认出是铃；第三层只看是否符合本片美术方向。
- 眼睛颜色对照第一层色值检查，不合格就重画。
- 参考图：`assets/ref/`（piapro 官方插画与服装设定图，仅作内部比对）。
