# 素材与提示词

人物不是每个镜头重新描述一遍，而是从同一张人设出发，在统一规则下生成当前镜头需要的姿态，再进入动画和合成。

## 从人设到镜头

1. 看[人设定稿](人设_定稿_c.png)与[人设提示词](人设_提示词.txt)，固定脸型、服装、比例和线条。
2. 看 [work/gen/prompts.py](../work/gen/prompts.py)：`IDENTITY` 是角色，`DRAW` 是画风，`HANDS` 是手部约束，`LARGE` 是大特写规则，`NEVER` 是应避免的细节；`ASSETS` 逐项说明镜头用途，`refs()` 决定附带哪些参考图，`build()` 拼成一次实际生成请求。
3. 看 [prompts_c.py](../work/gen/prompts_c.py) 与 [pick_c.py](../work/gen/pick_c.py)：早期 demo 的一批生成任务和选图处理。
4. 看 [src/tools/gen_batch.py](../src/tools/gen_batch.py) 与 [codex_gen.py](../src/tools/codex_gen.py)：当时怎样调用 Codex 内置生图并保留多次结果。
5. 看 [src/art/](../src/art/)：怎样抠图、清理边缘、整理平涂、定位黑条，再变成镜头可用的图片。

`codex_gen.py` 依赖当时 Codex CLI 的事件流和生成图片目录，工具版本变化后可能需要适配。阅读提示词、使用现成素材或渲染成片，都不要求重新调用生图。**运行生成脚本会使用你自己的模型账户和额度。**

## 素材目录怎样读

| 位置 | 内容 | 注意 |
|---|---|---|
| `docs/人设_定稿_c.png` | 统一人设 | 生成新姿态先带这张参考 |
| `work/gen/ref_sheet_hand.png` | 人设中手部的放大参考 | 避免近景手部变成另一种画风 |
| `assets/gen/cut/` | 抠好的人物和组件 | 多数尚未盖黑条 |
| `assets/gen/final/` | 已盖黑条、用于相应镜头的版本 | 不要误用未遮眼版本替换 |
| `assets/gen/standee/` | 十四种传言中的角色立牌 | 同一个角色，不同身份与服装 |
| `assets/gen/crowd/`、`extras/` | 人群与补充动作 | 参与场景叙事，不只是背景装饰 |
| `assets/gen/end/` | 正式结尾的分层与换张材料 | 包含眼睑、嘴、风中头发等变体 |
| `assets/gen/eyes/v4_a1_1.png` | 开眼默认使用的定稿高光图 | 已从本地实验目录补入版本库 |
| `assets/gen/raw/` | 正式段落直接读取的七张原始道具／画面图 | 其余 raw 候选仍不进入 Git |
| `assets/tex/` | 三维场景贴图 | 大多由工程生成或合成 |
| `assets/gen/bars.json` | 图上的黑条位置、尺寸、角度 | 按单图定位，不能只按脸框自动猜 |

`cut/` 与 `final/` 中有些文件同名，但角色状态不同，不是可随意去重的重复文件。不要只看文件名就替换。

## 开眼与结尾的制作记录

- [work/eye/prompt_v4.txt](../work/eye/prompt_v4.txt)：开眼高光的一轮具体提示词。
- [work/eye/key6/gen.py](../work/eye/key6/gen.py)：带人设与既有好图，比较整张主视觉的方向。
- [gen_end.py](../work/eye/key6/gen_end.py)、[gen_a3.py](../work/eye/key6/gen_a3.py)：眼睑、头发、嘴和手的补充生成任务。
- [build_end.py](../work/eye/key6/build_end.py)、[build_a3.py](../work/eye/key6/build_a3.py)：把生成图对齐到主图、切出图层并输出正式结尾素材。
- [picks.json](../work/eye/key6/picks.json)、[picks3.json](../work/eye/key6/picks3.json)：当时使用的候选对应关系。
- [src/clips/eye_anim.py](../src/clips/eye_anim.py)、[c6.py](../src/clips/c6.py)：最终按音乐时间组织的动画。

这些历史脚本保留原路径以便追溯，不是一个独立的“一键重建素材包”。候选原图和每次生成的全部结果没有完整公开；正式渲染所需的已选结果在 `assets/gen/end/`。重新生成只能参考方法，不能保证得到相同图片。

## 公开范围

| 状态 | 内容 |
|---|---|
| 已公开 | 正式渲染代码、已选人物图与贴图、人设、主要提示词、选录的结尾生成／处理脚本、分镜、问题与修改记录、节拍数值、成片剧照及静音节选 |
| 运行时下载 | 字体；清单在 [data/fonts.json](../data/fonts.json)，下载后保留各字体原许可 |
| 需要自备 | 原曲音轨、完整日文歌词、与音轨对应的罗马音卡拉 OK ASS |
| 本地生成 | `lyrics_timed.json`、EXR、场景编号表、渲染 PNG、缓存、分段视频与完整成片 |
| 未完整分发 | 被淘汰的生成候选、旧版成片、全部实验输入；部分历史脚本引用它们 |
| 不作为公开材料 | 原始聊天日志、账户信息、模型调用日志中的会话标识、私人预览页和本机维护资料 |

仓库并不包含制作时整个工作目录。公开的文件用于研究创作和实现；完整成片重跑仍受歌曲输入、对齐方式、字体和硬件环境约束。具体见[制作流程](制作流程.md)与[权利说明](../NOTICE.md)。
