# demo 分镜（六段，约 61 秒）

时间都是歌曲时间（秒）。每段用原歌对应位置的音频，段与段之间硬切。第一版分镜经过静音观众、歌迷、美术指导三方审查后改成现在这样。

## 全片统一的画法
- 色板：纯青 #03C3FB、墨黑、纸白、铃的金黄 #FEE45F；红只用于通知角标。
- 青色有含义：前面它是“外面的世界”（窗外、字牌、评论），最后一拍它属于她。
- 人物：定稿人设的画法，粗细变化的墨线、平涂、每种材质一档硬边阴影。
- 3D：Blender 只出数据通道，自己的代码上色和描线，规则与人物相同。笔触噪声贴在物体上（世界坐标），不贴屏幕，镜头运动时线不会游动。冷到极致时全屋是纸白、青、墨三色。
- 黑条：手绘马克笔，白色手写“少女A”。每张图单独定位，画进那张图里，逐张放大检查。
- 文字：日语。歌词逐字跟实际演唱出现。不让文字层级打架：每个版面最多两个大词。
- 她做了什么全片不说。不碰死亡：恶评不否定她的存在，不用 死ね、消えろ、いなくなれ、遺書、転落、行方不明 这类词；不用花瓶、遗像式构图、心电图式直线；结尾不切黑。

## 1. 开场：先有黑条，后有人（0.00–10.49）
前奏本身的停顿：0.2–1.2 一组、2.0–3.0 一组、3.2–3.7 静默、3.8–7.2 连续、7.2 收气、7.4 乐队进。
- 0.0–1.2：纯青空屏。马克笔涂出一条黑条。此时画面上还没有人。
- 2.0–3.0：白色手写一笔一笔写出“少女A”。
- 3.2–3.7：静默，画面完全不动。
- 3.8–7.2：墨线从黑条边缘沿着笔画长出去，头发、蝴蝶结、下巴、衣领依次出现（线从那张彩图提取，上色时不跳）。画面边缘开始零星冒出小评论。
- 7.4：乐队进，她一下子上色。她和黑条固定在画面中心，字从头发和蝴蝶结后面穿过去。每 2 拍换一种版面（竖排报纸、带粗边的电视字幕、评论流），每个版面只有两个互相矛盾的大词（優等生／不良）。拉丁字母 A 永远最醒目。
- 9.57 起：收成片名：大字“少女A”，署名“作詞作曲 椎名もた／歌 鏡音リン”。

## 2. 寒い×14：字钉进 3D 教室（69.30–81.31）
- 69.30–73.87：满屏一张平面的报纸头版，头版照片是盖黑条的她。歌词“時に躓いたって”逐字印上去（括号里的别人的话）。
- 73.87：第一块字牌把报纸钉在桌上。这一下让镜头升起：原来报纸平放在她的课桌上。窗外是一整片纯青，午后的大块硬边阳光爬在黑板和墙上。
- 14 次“寒い”，按唱法 5-5-4 三句升级：第一句大牌分散落在各处；第二句更密，扎成一片；第三句最大、离镜头最近。字牌是带厚度的青色字，斜着扎进表面，有真实投影。撞击的反应落在房间里（桌子一跳、灯管晃、粉尘），不震屏幕。相机只走一条慢弧线，不追落点。
- 同时越来越冷：阳光逐渐收窄消失，全屋走向纸白、青、墨；后段下雪，雪只积在朝上的面上。
- 78.96–81.31：“言い寄らないで”，粉笔自己写在黑板上。一间扎满字、积着雪的空教室，这时才来得及读字牌上的小标题。全屋只剩她桌上那份报纸还有一小块黄色。

## 3. 遠い×14：拉到她变成一个点（85.91–96.0）
- 85.91–88.7：同一间屋子的反打：雪和字牌都还在，她一直坐在那张桌子前。字牌当初是从她那个方向飞出去的。她是全屋唯一的黄色。桌沿真实挡住她，她向桌面和地板投硬影。
- 88.7 起：14 个“遠い”，对数距离匀速后退，每个字叠一个脉冲，不急停。屋顶是剖开的，所以始终看得到她。校舍 → 操场 → 街区 → 城市，窗外不再是纯青，外面的世界一切如常。她的屋顶合上。
- 从第 4 步起她用固定大小的黄点标记，不再变小，点上一小条黑线。“遠い”沿对数螺线排开，太小就淡出，不压在点上。转发数跳涨。
- 93.52 镜头停住；“傷つけないで”期间楼房连同影子一起沉下去、颜色换成地图色，3D 就这样变成 2D 地图，没有转场。地图上出现学校符号“文”、车站、虚构地名。

## 4. 14 个不同的 Rin（103.87–113.16）
用户决定（2026-11-05）：同一画风、不同穿着。每套衣服是一条关于她的传言，每张动作不同，盖同样的黑条。
- 一面 3D 的墙，14 个全身纸板立牌，离墙距离不同，吃同一个太阳的硬影，身后的墙上印着那条传言。镜头连续移动，不切，画面里始终看得到下一个的边。
- 节奏加速：第一个 3 拍，接着 3 个各 2 拍、4 个各 1 拍、6 个各半拍。
- 传言从可信走向离谱：学年第一的优等生 → 不良 → 大小姐 → 哥特萝莉 → 家里蹲 → 田径部王牌 → 想当偶像 → 画画的 → 送报打工 → 巫女 → 回乡下种地 → 正义的伙伴 → 其实是侦探 → 其实是外星人。
- 111.3 拉远：5×3 的网格，14 个人加中间一个空格。所有黑条不动，只从两端长出细线连成横线，线在空格两边断开。空格里是“本人より”和一个闪烁的光标（没有人问过她）。
- 歌词固定在底部字轨。

## 5. 憎い×14 和反转（154.2–164.3）
- 154.2–155.13：几乎空的评论区。底部输入框左边已经有她的黄色小头像和闪烁的光标（全屏只有这一点黄）。
- 155.13 起：14 个“憎い”，固定 2 列 7 行的槽位，顺序打乱，每次砸下一张恶评卡。卡片全部是灰白墨色，头像大、形状各异、名字各异。
- 160.20–160.67：一波翻过去，14 个头像全部变成同一个黄色头像，名字全变成同一个账号。停住，看清楚。
- 160.2 起：输入框里一个字一个字打出这句歌词“許されないの？”。她在打字。
- 161.13：画面退出，原来这是横握手机的屏幕，从她肩后看：她的手。输入框的字打完，约 162.4 打出“？”并发送，这句话变成第 15 张卡，还是同一个头像。
- 162.7（声音掉落）：切到正面，手机的光从下面硬边照着她的脸，盖着黑条。
- 162.7–164.3：对数匀速推进黑条（避开手写字），到全黑。

## 6. 开眼（193.93–203.42）
- 193.93–195.77“何番目でも”：暗色大特写，盖着黑条。她的手进画（和第 5 段同一只手、同样的袖口）。
- 195.77：黑条被她自己弄掉。候选做法：① 捏住一角撕下来；② 拇指一抹，墨迹被抹掉，方向和开场涂抹相反。两种都做出来比较。
- 195.77–197.62 第二句“何番目でも”：眼睛第一次出现：大而空，没有高光，完全不动。留一整小节让人看清。
- 197.62–200.38“僕が僕であるために”：11 个音节，每个音节往眼睛里加一层硬边的光。前 8 层只动暗部，后 3 层才真正亮起来，最大高光落在に。
- 200.38：句尾写出“？”（呼应前面的问句）。200.9 收气时问号的钩掉下来，只剩一点，再补两点，变成“…”。
- 201.4：乐队回来，硬切纯青底（和开场 7.4 同一个动作），这次满屏没有一个字，只有她睁着的眼睛。
- 之后她眨一次眼，眼神微微动起来。最后一帧停在青底和睁开的眼睛上，不切黑，声音在 203.42 收。
