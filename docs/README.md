# 制作资料索引

这份索引把原始制作记录与成片的实际实现串起来。想研究方法，先读整理后的三篇说明；想看具体决策和返工，再往下读原始记录。

## 建议阅读顺序

1. [制作手记](制作手记.md)：主题怎样影响视觉、人物素材为什么返工、审片怎样推动修改。
2. [素材与提示词](素材与提示词.md)：从人设、提示词到最终素材；已公开和自备的内容。
3. [制作流程](制作流程.md)：环境、输入、正式入口、单段预览、3D 渲染与全片拼接。
4. [全片分镜](全片分镜.md)与 [src/assemble_full.py](../src/assemble_full.py)：把叙事段落对应到实际模块和帧区间。
