# 方案：《谁是少女A》

## 一句话
有个女孩上了新闻，报道里她只叫“少女A”。所有人都在说她是谁，说法全都不一样，却没人问过她。片子从外面的声音一路走进她心里，直到最后才第一次看见她的眼睛。

## 主题
她不希望别人关注“少女A”这个代号，而是关注她这个人。到后来，她自己也开始用“少女A”的眼光看自己。

深层对应（不明说）：大家都在意椎名もた，没人关心溝口遼。故事来自作者生前的经历和感受，和他的死无关，片中不碰死亡。片中不出现他的形象、生平和本名；姓名栏写的什么，始终不给观众看。署名只写“作詞作曲 椎名もた”。

## 已定的决定
- 她做了什么全片不说，只有互相矛盾的说法。
- 全片黑条遮眼，最后开眼：眼睛从空洞变成闪亮。做法到时对比几种方案。
- 恶评都是她自己写的：这个反转要。
- 门外的人全程不出现，只有敲门声和留言。
- 片中文字都用日语。
- 先开眼（3:14 附近），再到尾奏，她在姓名栏写下第一笔就切黑。
