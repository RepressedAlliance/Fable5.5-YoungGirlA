## 怎么写一段
- 看 `src/engine.py`（Clip、Type、fit、draw_image、rect、缓动函数）、`src/clips/common.py`（Strip 歌词纸带、chars_of、LYRICS、duotone）、`src/clips/c5.py` 和 `c1.py`（完整例子）。
- `draw(c, t)` 用 Skia 画一帧，t 是歌曲秒。需要运动模糊就实现 `blur(t)` 返回子帧数，并设 `shutter`（默认 0.5，快动作用 0.25 以下）。硬切时刻写进 `cuts`，快门不会跨切点。
- 预览：`.venv\Scripts\python.exe src\tools\preview.py 模块 类名 t1 t2 ...`，得到 `work/qc/<name>_sheet.jpg` 和单帧 `work/qc/<name>/s*.png`。这是唯一的出片方式，不要跑全段渲染，也不要跑 Blender（3D 段除外）。
- 歌词：`K.LYRICS[i]`，`K.chars_of(i, "文字")` 取每个字的演唱时间，逐字跟唱，不整句预显示。字幕用纸带 `K.Strip`，位置固定在下方。歌词行号见 `docs/全片分镜.md` 的歌词和 `work/analysis/lyrics_timed.json`。
- 节拍：`from timeline import beat_time, bar_time`（`src/timeline.py`）。切换和撞击落在拍或音节上，不要落在别处。

## 画法规则（硬性）
- 色板：纯青 `E.CYAN`、墨黑 `E.INK`、纸白 `E.PAPER`、铃的金黄 `E.RIN`、红 `E.RED`（只用于通知角标和红笔）。其他颜色要克制。
- 平涂、硬边，不用柔光、渐变、发光。粗细有变化的墨线。不用模板式动效（匀速滚动、淡入淡出、缩放弹跳的滥用）。
- 动作要有节奏：缓入缓出、踩拍，不要忽停忽跳，也不要急停。人物图不做局部抠动，不做逐帧生成。人物图一张只用于一个镜头。
- 黑条必须完全盖住眼睛和睫毛。用 `assets/gen/final/<id>.png`（已经画好黑条），不要用 `cut/` 里没盖黑条的（她的背影、手、脚除外）。
- 片中文字都用日语，字号测量后再放（`E.fit`），不能超框、被切。竖排要用 `vertical=True`。竖排多列从右往左。
- 不碰死亡：不用花瓶、遗像式构图、心电图式直线；评论只骂言行，不用 死ね、消えろ、いなくなれ、遺書、転落、行方不明。不出现作者的名字和形象。
- 现实常识：用户逐帧看，手、脚、纸张、物体接触、影子方向都要合理，不能有悬空、穿插。
- 故事要关声音、不懂日语也能看懂。

## 素材
- `assets/gen/final/`：盖好黑条的人物。`p01_bust_front`、`p02_seated_high`、`p04_face_lit_by_phone`、`w01`..`w14`（传言）、`g01`..`g05`（奔跑和站立，侧面）、`t01_candid_turn`、`t03_candid_hand`。
- `assets/gen/cut/`：抠好未盖黑条。`t02_candid_gate`、`o01`..`o04`（背影、脚）、`h01_pen`、`h02_pen_low`、`h03_push`、`h04_marker`、`p03_phone_over_shoulder`（屏幕是洋红，`C.key_magenta` 抠掉）。
- `assets/gen/raw/`：`k01_flowers.png`（白纸上的两朵蜡笔花）、`r01_id_photo`、`r03_crayon`、`r12_chalk`、`r14_tabloid` 等旧画风图（03 段当旧物用，这些图眼睛未遮，要盖黑条，用 `src/art/bar.py` 的 Bar 手工定位，不能露眼）。
- `src/art/bar.py`：马克笔黑条和手写“少女A”（笔画数据 HAND 是手写字的例子）。
- 字体：`assets/fonts/ttf/`，常用 `ShipporiMinchoB1-ExtraBold`（报纸、大字）、`ZenKakuGothicNew-Black/Bold/Medium`（界面）。
- 3D：`src/three/kit.py`、`classroom.py`、`city.py`，上色 `src/npr/comp.py`，例子 `shot_c2.py`、`paint_c2.py`、`shared_c2.py`，串联 `src/three/pipeline.py`。
